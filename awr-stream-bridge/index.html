AWR Stream Bridge プライバシーポリシー

最終更新日：2026年10月23日

藍・W・楽歌（以下「作者」）が提供する Chrome 拡張機能「AWR Stream Bridge」（以下「本拡張機能」）における、情報の取り扱いを定めます。

1. 取り扱う情報

  • 利用者が設定画面で入力した、OBS Studio の WebSocket の接続先とパスワード
  • 対応サイト（BuzzIn.live のホスト画面）に表示される、参加者の表示名・押した順・得点・接続状態・部屋コード
  • OBS に接続したツールから届く命令（早押しの解除、得点の加減、参加者を外す）

2. 利用目的

OBS の接続先とパスワードは、利用者自身が使う OBS Studio への接続にだけ使います。BuzzIn.live の画面の情報は、その OBS Studio へ中継するためにだけ使い、OBS から届いた命令は、利用者が開いている BuzzIn.live のホスト画面へ反映するためにだけ使います。

3. 保存

  • OBS の接続先・パスワード・設定は、利用者のブラウザ内（chrome.storage.local）にだけ保存し、ほかの端末と同期しません。
  • 参加者の表示名などの中継内容は保存しません。

4. 第三者への提供・外部送信

本拡張機能は、利用者が設定した OBS（利用者自身のPC、または同じ家庭内・社内ネットワークにあるPC）以外へ、いかなる情報も送信しません。作者が情報を受け取ることもありません。利用状況の収集、広告、解析ツールは使用しません。

5. 情報の削除

設定画面の「設定をすべて消す」を押すか、本拡張機能を Chrome から削除すると、保存した情報は消えます。

6. 改定

本ポリシーを改定するときは、このページで告知します。
